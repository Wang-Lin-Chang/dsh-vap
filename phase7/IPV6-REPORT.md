## 直连实测（对照组格式）

| 测试 | 目标 | 结果 |
|------|------|------|
| 服务器 → 公网 v6 出网 | 2400:3200::1（阿里 DNS） | 3/3 通，avg 42.5ms |
| 本机 → 服务器 v6 ICMP | 2402:4e00:1209:c100:6:59cc:69f4:7951 | 3/3 通，24-52ms（avg ~30ms） |
| 本机 → 服务器 v6 UDP 回显 | 同一地址:45013 | PONG 收到，直连数据面通 |
| 重启后本机 → 服务器 v6 ICMP | 同一地址 | 3/3 通，24-39ms |

对照组：Tailscale ULA（fd7a::/48）v6 数据面不通（Windows 客户端 GUI 模式吞包，v4 通 v6 不通，双向 0 包）——公网 v6 直连与其无关，独立成立。

## 关键数字

- IPv6 地址：VPC /56 + 子网 /64 + 实例 /128（GUA/BGP，内外网同地址）。
- RTT：家庭 ↔ 腾讯云北京 v6 约 30ms（与 v4 公网路径同量级）。
- 费用：内测期 IPv6 地址费免；公网按流量 0.8 元/GB；实例按量 0.37 元/时 + 盘 ~0.05 元/时（测试结束释放）。
- 持久化：netplan 60-ipv6.yaml（dhcp4 on / dhcp6 off / accept-ra off / 静态地址 / 静态 ::1 默认路由）。
