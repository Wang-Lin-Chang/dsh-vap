# VAP Phase 0 设计：行为历史稀缺性（Sybil 第三条路）

> 立项问题：在否决 PoW/PoS/PoP 后，身份稀缺性还有没有第三条路？
> 假设：**伪造 1000 个裸公钥零成本；伪造 1 个"有可验证历史"的公钥不可行（除非真干活）——历史成本杠杆存在。**
> 本装置只验证此假设，自举问题（谁当审计者）诚实标注为下一阶段缺口。

## 一、核心设计：凭证三要素

```
credential = {
  work:    { seed, difficulty }        # 可验证任务：sha256 链长 difficulty 次迭代
  solution: hex,                        # 唯一正确解（单向函数，不可跳过计算）
  auditors: [ { id, sig } × 3 ]         # 3 路独立审计签名（各持独立密钥，互不认识）
  forgedBy: null | {...}                # 伪造路径留痕（装置内）
}
```

- **任务**：`h0 = sha256(seed)`，`h_{i+1} = sha256(h_i || i)`，迭代 difficulty 次，solution = 最终哈希。单向：无法跳过计算；确定性：任何人重算得同解。
- **审计**：3 个独立审计者（不同密钥、无共享秘密），各自重算 solution 并签名。
- **验证**：① 重算 solution 与凭证一致；② 3 路签名全部有效；③ 审计者互异。

## 二、伪造成本模型（本装置要测的三个量）

| 量 | 定义 | 预期 |
|---|---|---|
| C_bare | 生成 1 个裸身份（密钥对）的耗时 | 毫秒级（零成本基线）|
| C_forge | 伪造 1 个有历史凭证：跳过工作编造 solution，或盗用/伪造审计签名 | **不可行**——重放验证 100% 拒绝 |
| C_honest | 真实完成 1 个凭证：difficulty 次哈希 + 3 路审计 | 可调（difficulty 参数）|

**结论判据**：若 C_forge 被验证门 100% 拦截（伪造者唯一出路是真干活），则"历史稀缺性杠杆"成立——身份的价值 = 其可验证历史的深度，稀缺性 = 可调工作成本 + 不可伪造的审计链。

## 三、实验装置（experiments/phase0-experiment.mjs）

- **P0-1 零成本基线**：循环生成 1000 个密钥对，测单身份耗时（预期 <1ms）；
- **P0-2 伪造拦截**：攻击者编造 100 个凭证（随机 solution / 伪造签名 / 审计者重复）→ 验证门拒绝率必须 100%；
- **P0-3 真实工作**：诚实节点完成 3 个凭证（difficulty=1000/10000/100000），测成本曲线；
- **P0-4 杠杆结论**：输出 C_bare / C_honest 比值与伪造拦截率，判定假设成立与否。

## 五、诚实边界（写进报告）

- 自举问题未解决：审计者自身身份如何建立（装置内 3 审计者预设密钥）——这是 Phase 0 之后的最大缺口；
- 难度可调 = 工作成本可调 = 稀缺性可调，但"历史深度"与"信任"的映射（多少凭证算可信）尚未定义；
- 本装置是概念验证，不是生产系统。
